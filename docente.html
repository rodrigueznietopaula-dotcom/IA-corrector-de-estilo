Implementación, recursos y seguimiento

Esta vista está separada de la experiencia del estudiante. Aquí se concentran la secuencia, los recursos, las instrucciones y el espacio de seguimiento.

📚 Estructura de la secuencia

Sesión 1 · Producción inicial

Apertura: saberes previos, cuento modelo, patrón y rúbrica. Desarrollo: primer borrador sin IA. Cierre: socialización, autoevaluación y guardado.

Sesión 2 · Revisión con IA

Protocolo, ingreso a Copilot, Versión 1, prompt, preguntas/pistas y Versión 2.

Sesión 3 · Final y metacognición

Revisión final, Versión Final, rúbrica, comparación de tres versiones y reflexión.

👥 Seguimiento de estudiantes

Decisión de arquitectura: no recomiendo crear contraseñas propias y guardarlas dentro del HTML de GitHub. Para estudiantes de sexto, y especialmente por tratarse de datos educativos de menores, la autenticación y los datos deben quedar fuera del repositorio público.

Opción recomendada

Usar las cuentas institucionales Microsoft 365 que ya exige el protocolo. Registrar las evidencias mediante Microsoft Forms/Excel/OneDrive/SharePoint. Así no se crean nuevas contraseñas para los estudiantes.

Alternativa Google

También puede utilizarse Google Forms + Sheets, pero requerirá configurar correctamente la identificación de estudiantes y los permisos. No recomiendo publicar nombres, correos, contraseñas ni códigos en GitHub.

Datos que podemos registrar

Estudiante/identificador institucional, etapa alcanzada, fecha, versión 1, versión 2, versión final, sugerencia acogida, reflexión y resultado de rúbrica.

🔐 Lo que haremos cuando me compartas la lista

Podemos preparar una estructura de usuarios para el sistema elegido, pero no pondremos contraseñas ni datos personales en el HTML público. Primero definiremos el método de autenticación y el lugar seguro donde se almacenará la información.

🧭 Orientaciones rápidas para el docente

Antes

Verificar cuentas Microsoft 365 y acceso a Copilot; socializar protocolo; preparar patrón, rúbrica y prompts.

Durante

Supervisar que la IA intervenga después del borrador y que el estudiante tome y justifique sus propias decisiones.

Después

Controlar versiones, rúbrica, resultados y metacognición; consolidar conclusiones sobre el uso de IA.
