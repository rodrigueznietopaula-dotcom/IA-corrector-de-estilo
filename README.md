# Escribo, reviso y aprendo

Micrositio interactivo para la secuencia didáctica de Lengua Castellana, grado sexto.

## Archivos
- `index.html`: página completa. Incluye HTML, CSS y JavaScript en un solo archivo.
- No requiere servidor ni instalación de dependencias.

## Publicarlo en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama principal y la carpeta `/root`.
6. Guarda. GitHub generará el enlace público del sitio.
